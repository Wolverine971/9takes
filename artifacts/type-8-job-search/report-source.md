## Type 8 synthesis

Repository sources consistently describe healthy Type 8 performance as decisive, direct, autonomous, mission-driven, and protective. The job-search failure mode is lone-wolf overcontrol: pushing harder at the same tactic, refusing allies, making work invisible, and turning every gatekeeper into an opponent. The operating persona therefore channels intensity into a bounded target list, uses allies and visibility deliberately, treats rejection as data, and dials interview intensity down without becoming vague.
