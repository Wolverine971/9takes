# Blog sidecars

Non-post files that used to sit beside live posts in `src/blog/`: social cut-downs
(`.instagram.md`, `.twitter.md`, `.reddit.md`), review notes (`.review.md`), source
material and working notes. Moved here on 2026-11-13 so the blog loaders no longer
depend on hand-written glob exclusions to skip them. The folder layout mirrors
`src/blog/`.
