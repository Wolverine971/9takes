## Quick Brand Reference

The canonical message system is locked in
[`messaging-hierarchy.md`](./messaging-hierarchy.md). Do not introduce a new master concept without
an explicit decision to replace one of these levels.

| Level                   | Canonical language                                              |
| ----------------------- | --------------------------------------------------------------- |
| **Movement belief**     | The internet collapses nine perspectives into one winning take. |
| **Brand promise**       | See the emotions behind every take.                             |
| **Product ritual**      | Answer before the crowd.                                        |
| **Product explanation** | One question, nine perspectives.                                |
| **Personal payoff**     | Stop mistaking someone else’s alarm for a defect.               |

**Positioning:** 9takes protects your honest first read, then shows how nine different emotional
patterns interpret the same situation so you can understand yourself and others better.

## Voice Attributes (Quick Reference)

| Trait                           | Description                        | Example                                                                       |
| ------------------------------- | ---------------------------------- | ----------------------------------------------------------------------------- |
| **Tactically Direct**           | No fluff; actionable info          | "Type 6s signal loyalty through questions—answer them, don't get defensive."  |
| **Socially Savvy**              | Connect insight to real-world wins | "Read the room: Type 8s respect directness, Type 9s need gentle approach."    |
| **Respectfully Provocative**    | Challenge comfort zones            | "If your social circle always agrees with you, you're missing crucial intel." |
| **Pattern-Recognition Focused** | Show emotional logic               | "She's not 'being difficult'—Type 1s need things done right the first time."  |
| **Results-Driven Coach**        | Focused on outcomes                | "Try this approach tonight and watch the dynamic shift."                      |

## Content Approach

### Dual-Title System (Celebrity Content)

| Field        | Purpose        | Style                    |
| ------------ | -------------- | ------------------------ |
| `title`      | Page headline  | Evergreen, authoritative |
| `meta_title` | Search results | Clickbait, CTR-optimized |

### Writing Rhythm

```
Hook · Insight · Action step
```

### Key Verbs

Decode, navigate, map, read, unlock, resolve

### Never Use

- Academic/theoretical tone
- Hedging language ("tend to", "might")
- Generic descriptions
- Unsubstantiated claims
