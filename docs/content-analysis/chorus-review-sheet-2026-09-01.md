## Publishing an approved question

One person at a time, once the wording is final:

```bash
node scripts/generate-chorus.mjs --slug=<person> --question="<approved copy>" --publish
```

That creates the backing `questions` row and generates its nine takes. When every published page has a CTA again, this returns nothing:

```bash
./scripts/db-query.sh "SELECT person FROM blogs_famous_people WHERE published=true AND chorus_question_url IS NULL"
```

## Why this list exists

Chorus coverage was 100% through May 2026, 34.8% in June, and 0% from 1 July onward. `generate-chorus.mjs` needs a human-reviewed question plus an explicit `--publish`, and it was wired into no publish command and no cron, so it was only ever a manual step and it stopped being run. `/blog_content_publish_people` now has a required step that prevents this recurring.
