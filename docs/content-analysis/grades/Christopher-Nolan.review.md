**Transferable finding beyond this draft:** `blog-source-audit.mjs` only inspects tagged quote slots, so a Testimony Ledger entry can read as verified while the reader-visible sentence carries no attribution at all. Any grader relying on a clean audit report will systematically miss un-quoted named charges (`X called it Y`) and quoted-but-untagged asides. Worth a script change: flag capitalized proper-noun attributions in the body that have no outlet within the sentence.
