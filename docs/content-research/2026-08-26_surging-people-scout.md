  Pierre/`Lanterns` cluster. Google's comparison endpoint returned HTTP 429, so no relative-interest

  dates/casts against studio/franchise pages or reputable current reporting.
- **Platform checks:** used Billboard/Luminate for Tate McRae and current channel trackers plus
  current profiles for Nick DiGiovanni. Platform growth is not presented as Google search volume.
- **Confidence:** future movie demand is labeled CALENDAR FORECAST until direct search or platform
  data arrives. Scores are a decision rubric, not keyword volume or SEO difficulty.
- **Not performed:** a full top-ten SERP/entity-gap audit for each CREATE name. Joseph Zada and Tom
  Rhys Harries should be routed through `/find-emerging-entity-gaps --single` before drafting.
- **No queue mutation:** `docs/blog-automation/backlog-queue.json` and `override.json` had pre-existing
  user changes. This run did not edit either file.
