**Purpose:** Faceless (text-on-screen) Reel scripts adapted from published personality-analysis carousels. No camera required.
**Defers to:** [`../personality-series-north-star.md`](../personality-series-north-star.md) — one lore beat → the question it raises → "full read on 9takes." The "catch" line in each script is drawn from DJ's own published caption, so it stays on-voice.

## The reusable template (so every person-post becomes a Reel the same way)

**Why this shape:** the first ~1 second must stop the scroll _with sound off_, so the hook is on-screen text over the face. It holds watch-time with an open loop (callout → proof → the catch) and ends on a question that loops back so it replays. Replays + sends buy reach.

**6 beats · 15–20 sec · text-on-screen over the existing carousel art with a slow zoom:**

1. **Hook (0–1.5s):** recognizable face + one bold claim. Must be muted-readable in 1 sec.
2. **Callout (1.5–4s):** the symptom line that makes that type feel _seen_.
3. **Proof (4–9s):** 2–3 fast, vivid, insider facts (five-test filter from the north star). Quick cuts.
4. **The catch (9–13s):** the shadow line — the save-worthy insight (pulled from the caption).
5. **CTA + loop (13–18s):** a question + "send this to the [type] in your life" + "full breakdown in bio."

**Audio:** a trending-but-not-everywhere moody/cinematic sound (trending audio adds reach). Voiceover optional (boosts watch-time, still faceless) — text carries it without.

### Build each in ~10 minutes (CapCut or Canva)

1. Import the carousel images (cover + interior slides) as a video.
2. Add a slow zoom/pan to each (CapCut auto-does this).
3. Drop the text cards at the timings below; put the **hook card on frame 1**.
4. Add a trending moody sound at ~15% volume.
5. Export 9:16, post, then **reply to any comment in the first 30 min**.

### Caption skeleton (fill-in-the-blank)

```
[Name] is Enneagram Type [N] — [the Role]. [1–2 lore beats, flat delivery, no verdict].
"[the catch, in their words or ours]." [The pattern] → full breakdown in bio.

Send this to the Type [N] [who ____]. 👇
#[celebrity] #enneagram #enneagramtype[N] #[role] #personalitytypes #9takes
```

**Send-CTA is the money line** — DM-shares are weighted 3–5× likes, so "send this to…" beats "tag someone" (a tag drives comments; a send drives shares). Vary the "who ____" per type.

> **Optional test (later, don't change now):** the censored-eyes look is distinctive, but eyes are how people recognize faces. Worth A/B-ing one Reel where the hook frame shows the _un_-censored face, then the bar slams down as the reveal. Track reach/saves against a standard cut.
