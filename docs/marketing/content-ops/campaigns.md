# Active Marketing Campaigns

These campaigns keep the feed coherent. Every queue item belongs to one of them.

## 1. Personality Lore Stack

**Promise:** Specific, insider facts reveal the engine beneath a public figure, then offer one humble window into the inner world without pretending to diagnose them.

- Primary format: three-slide lore carousel — cover, lore stack, “A Window Inside”
- Companion: one-tidbit Reel and story poll
- Cadence: 2 carousels/week
- Audience ponds: pop culture, creators, self-improvement, personality typing
- CTA: full personality breakdown on 9takes; ask which fact creates the biggest question
- Success: profile actions, shares, qualified comments, link taps
- Editorial contract: `docs/instagram/personality-series-north-star.md`
- Inner-world contract: `docs/marketing/content-ops/templates/window-inside-slide.md`
- Current bank: Tim Ferriss, Sabrina Carpenter, Charli XCX, Robert Greene, Pedro Pascal; Kai Cenat remains blocked on one source check

## 2. One Situation, Nine Takes

**Promise:** The same visible behavior can come from nine different motives; find the one that is yours.

- Primary format: 9-type gallery/decoder carousel
- Companion: forced-choice story poll or short comparison Reel
- Cadence: 1 carousel/week
- CTA: comment your type, save your slide, send a friend theirs
- Success: save rate, share rate, substantive self-identification comments
- Current bank: self-sabotage gallery, one apology nine ways, stress surfaces/nine fuels, Enneagram cheat-sheet pilot

## 3. Pattern Lab

**Promise:** A useful mechanism for reading behavior more accurately, proved with a real person or situation.

- Primary format: diagnostic/how-to carousel
- Companion: 30–45 second mechanism Reel
- Cadence: 0–1 carousel/week plus one Reel when the idea supports it
- CTA: run the diagnostic on yourself or someone you know
- Success: saves, shares, repeat profile visits
- Current bank: Robert Greene “read emotion > motive > behavior,” three centers/three needs, Type 3 competence theater

## 4. Carousel-to-Reel Reach Loop

**Promise:** The strongest beat from a proven carousel, compressed for non-follower discovery.

- Primary format: 20–40 second Reel with embedded captions
- Cadence: 2 Reels/week
- CTA: see/save the full carousel or read the full breakdown
- Success: non-follower reach, 3-second hold, completion rate, profile actions
- Current bank: Chappell Roan, Lana Del Rey, Steven Bartlett scripts
- Rule: do not reopen research unless the script contains a flagged claim

## 5. Rising-Tide Creator Relationships

**Promise:** Become a useful, recognizable peer to emerging personality and psychology creators before asking for collaboration.

- Format: thoughtful comments, story replies, contextual DMs, then collaboration pitches
- Cadence: 5 useful touches/day; 2 pitches/week only after repeated interaction
- Target pool: 10K–100K emerging creators and high-fit adjacent accounts in `docs/instagram/account-profiles/`
- CTA: smallest useful yes—co-created comparison, shared prompt, or source swap—not a generic meeting
- Success: replies, follow-backs, reciprocal engagement, accepted collaborations
- Guardrail: no automated sending, generic praise, fabricated familiarity, or cold pitch before a credible reason exists
- System reference: `docs/outreach/cold-outreach-system.md`

## Campaign balance rule

Across any rolling ten feed posts:

- 4 Personality Lore Stack
- 2 One Situation, Nine Takes
- 2 Pattern Lab
- 2 Carousel-to-Reel

This mix is a guardrail, not a prison. A timely post can replace a slot if its source is verified and the following ten-post window restores the balance.
